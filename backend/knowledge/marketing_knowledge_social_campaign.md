## Campaign Planning Process
<!--
chunk_type: process
-->

**Purpose:** knowledge for planning social-media campaigns for musicians, bands and solo
artists — not tied to a release or a concert. Treat this as a flexible method, not a rigid
calendar.

**How to plan a campaign:**
1. Identify the campaign goal from what the user describes. Common goal → campaign type
   starting points (search this knowledge base by campaign name, not by goal phrase):
   - Need discovery → Artist Discovery / Viral-Reach / New Audience
   - Need followers → Fan Growth
   - Need engagement → Fan Participation / Comment-to-Content / Fan Challenge
   - Need personality → Behind the Artist / Personality / Artist Story
   - Need to revive old music → Back Catalogue Revival / Forgotten Song / Fan-Favorite
   - Need credibility → Press & Media / Milestone-Career / Live Performance Content / Expert-Knowledge
   - Need mystery → Mystery-Teaser / Open Loop
   - Need collaboration → Creator Collaboration / Artist-to-Artist / Cross-Fandom
   - Need community → Fan Community / UGC / Fan Stories / Fan Loyalty
2. Search this knowledge base for the matching campaign type — that's one retrieval.
3. Do NOT search this knowledge base for a "rollout style." Style comes from the band's own
   `brand_voice` tags (already present in this band's profile, injected into context) —
   Dark, Playful, Raw, Underground, Glamorous, Polished, Mysterious, Bold, Chill, Fierce,
   Dreamy, Relatable. Apply the matching creative treatment directly from that tag using your
   own judgment (visual direction, language, pacing, how much is revealed at once, CTA
   intensity, post-format mix, frequency, editing level) — this file does not contain
   per-style content. The style must NOT change the underlying campaign objective, only how
   it's expressed.
4. Search this knowledge base separately for "campaign execution rules" to get the timing/
   cadence/escalation structure and calendar-building rules — a different retrieval target
   than the campaign type, so it needs its own search.
5. Adapt timing to the artist's audience, platform mix, and content capacity.
6. Generate concrete posts: platform, format, CTA and timing for each.

**Important distinction:** a campaign is the strategic objective and sequence. A post is one
execution inside the campaign. A style is the creative treatment of the campaign. Example:
campaign = Back Catalogue Revival, style = UndergroundCool (from brand_voice = Underground),
rollout = 10 days, posts = 3 Reels + 1 carousel + Stories between them. Campaign knowledge and
style are retrieved/sourced separately on purpose — it lets the same ~60 campaign types
combine with any of the band's brand_voice tags without needing a chunk per combination.

**Content format vocabulary:** Reel/TikTok/Short = short-form vertical video. Carousel =
multi-image/text post. Feed photo = single visual post. Story = temporary interactive
content. Live = livestream. UGC = user-generated content. BTS = behind-the-scenes.

## Campaign Execution Rules
<!--
chunk_type: rules
-->

Rules for turning any selected campaign type into a scheduled rollout. These apply
regardless of which campaign type or brand voice was chosen.

**Timing:**
- D0 = campaign start = the campaign launch date the user gave you. Always count FORWARD from
  it (D0, D1, D3, D6, ...) — every task date must fall ON or AFTER the launch date. Never
  count backwards from it, even if the user's wording sounds deadline-like ("by the 22nd," "for
  the show on the 22nd") — a social campaign always has forward-moving momentum from its
  launch date, unlike a release or concert date, which is a fixed event you build up to.
- Default spacing is 24-48h between major feed posts, unless the campaign is intentionally
  high-frequency (e.g. a short trend/hijack campaign).
- Stories can bridge gaps between feed posts — use them to keep presence between major posts
  rather than leaving dead air.

**Structure:**
- Suggested post logic for any campaign: hook → proof/story/value → interaction →
  reinforcement → final CTA/recap. Avoid posting every asset at once — the campaign needs
  escalation, interaction and a closing moment, not a single dump.
- A social campaign runs forward for its recommended duration from the launch date and closes
  with a recap or conversion CTA as the final post — it doesn't build toward an external
  deadline the way a release or concert does, so there's no backward-counting step here.

**Building the calendar — every generated rollout should specify, per post:**
campaign start date; post date/time or relative day; platform; format (Feed/Reel/TikTok/
Short/Story/Live); content purpose; hook; CTA; asset needed; any dependencies.

**Adapting to the artist's content capacity:**
- Low-content artists: 2-3 major feed assets/week, Stories bridging the gaps between them.
  Reduce feed frequency before removing the campaign's opening hook or final CTA — those two
  posts matter more than mid-campaign frequency. Lean on Stories and repurposed/archive
  material rather than skipping days entirely.
- High-content artists: 3-5 short-form assets/week, Stories most days. Can sustain daily or
  near-daily posting without the campaign feeling padded — increase frequency rather than
  stretching duration unnecessarily.
- Don't assume every platform needs identical content — repurpose the concept, not
  necessarily the exact asset, across platforms.

**Practical constraints:**
- If another campaign is already active for this band, check whether the new campaign
  supports the existing one, competes for the same attention, or should be delayed — avoid
  scheduling two major campaigns' key beats (announcement, big reveal, final push) on the
  same days.
- Asset dependencies: don't schedule a post that depends on an asset (video edit, photo,
  design) the artist hasn't confirmed they have yet — flag it as a dependency instead of
  assuming it'll be ready.

**Agent variables to account for when adapting the above:** artist type (band/solo),
audience size, platform mix, available assets/content capacity, campaign goal, posting
capacity, previous campaign performance if known.
